## 建议拍法

- 运行 `dist/ANGEL GAME v2.exe`（或 `python main.py --demo` 演示模式）后截图。
- 主界面建议展示几张带封面的卡片 + 底部「今日进度」与「更新检查 (N)」按钮。
- 统计面板建议展示日历热力图（某月）与连续游玩天数。
- PNG 即可，宽度建议 ≥ 1000px，避免过大（单张 < 1MB 为宜）。

补好图片后，README 中的 `![主界面](docs/preview-main.png)` 等引用会自动渲染，无需改其它文件。q
